Project One

The program is a python-based application designed to help users manage and organize their spendings with other people digitally. As traditional paper-based receipt management systems are inefficient and time consuming, this project’s goal is to provide a digital solution to this problem by intricately programing in such a way it provides an excellent solution. Even though managing a list of receipts through excel is a good solution, as the data grows, management of data in excel becomes a brain knot especially when you want to revisit your data; as a result, this hinders one’s ability to be productive and efficient. This program aims to make retrieval of information simple, effective, and efficient. Some key features of the Receipts Manager (Version 1) include receipt capture via user input through the terminal, centralized storage. This program is targeted towards people that depend on sharing spending such as people living in a household together, traveling together with families or friends, and dining with a group of friends, etc. All in all, the program allows the user to save and organize receipts with dates efficiently and access the receipts through a terminal based User-Friendly Interface.

Tech Used: React, Node.js
